Elaru


An ambitious virtual reality stealth adventure game made with a team of 8 students.

I enjoy learning new software, so for this project I learned how to use Adobe Audition for creating sound effects with visual references.


Contribution:
As project lead and programmer I generally focused on UX, which consisted of polishing the functionality and interaction with the world and weapons.

Besides UX, I was also in charge of implementing all the audio in the game.

 

Applications used:

Visual Studio 2017, Unity 2017, SourceTree, Photoshop, Audacity, Audition and Slack.
