Arnoid

 

A very simple remake of Arkanoid for Android, made whilst learning Cocos2d-x. You can angle your shots using the gyroscope functionality of your device.

Side note: I mostly put my time in learning the API for Cocos2d-x during this project, so everything is horribly crammed in a single main function.

 

Applications used:

Visual Studio 2015, Cocos2d-x, Android Studio and TexturePacker.
