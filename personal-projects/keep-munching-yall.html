Info

A third-person wave-based roguelite pizza throwing game about feeding "customers" in a world taken over by people infected with a gluttony virus.

Development

Inspired by one of my favourite games at the time, Risk of Rain 2, and created in s&box with the intent of exploring some of the platform integration like community maps.

Tech

  • Engine & Code
    • s&box
    • C#
    • Razor (HTML + CSS + C#) for UI
  • Art & Audio
    • Affinity Photo 2
    • Affinity Designer 2
    • Audacity
  • Workflow
    • Various AI tools (to help with writing code occasionally)
