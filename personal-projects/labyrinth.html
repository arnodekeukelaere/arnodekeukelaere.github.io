Gameplay

Networked Unity game where one player plays the minotaur roaming the labyrinth finding intruders and the other plays the poor soul trying to escape it.

(It's currently not available to play publicly since it has costs associated with it for the networking)


What I did

Gameplay and UI programming. For this jam I challenged myself to learn features of Unity I've never used before, that being:

  • UI Toolkit
  • Netcode for Gameobjects
  • Relay (for server hosting)
