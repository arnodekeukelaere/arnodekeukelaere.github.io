Labyrinth

A 48-hour game jam game, made with colleagues from d3t, about escaping a labyrinth plagued by a minotaur.

Overview

This was a 48-hour game jam project created in collaboration with colleagues from d3t. The game features an escape-the-labyrinth theme with a relentless minotaur antagonist hunting players through darkened stone corridors.
